NurseCall — loyiha tekshiruvi, 2026-10-04
======================================

Tekshiruv lokal repozitoriy bo‘yicha bajarildi. Ishlab turgan klinikalar, production server yoki haqiqiy qurilmalarga so‘rov yuborilmadi. Dastur kodi o‘zgartirilmadi. Quyidagi xulosalar kod tahlili, lokal tekshiruvlar va alohida `nursecall_review_20261004` Postgres bazasidagi tajribalarga asoslangan.

Tizim tuzilishi
---------------

`ESP32 / RF tugma → FastAPI → PostgreSQL → WebSocket / push → veb, telefon, soat`.

Serverda router/service/repository qatlamlari, klinika bo‘yicha ajratish, billing, audit, qurilma aniqlash va rejalashtirilgan monitoring ishlari bor. Veb React/TypeScript’da, asosiy yangi mobil ilova Flutter’da, avvalgi mobil ilova Expo’da, soat ilovasi Kotlin’da yozilgan. Dizayn qiymatlari `tokens.json` orqali generatsiya qilinadi.

Yaxshi yechimlar: chaqiruvni atomar tasdiqlash, xona bo‘yicha advisory lock, `press_id` bilan qayta yuborishni tanish, billingdan ajratilgan faol chaqiruv yo‘llari, WebSocket uzilganda HTTP polling, qurilma kalitlarini HMAC’ga bosqichma-bosqich o‘tkazish, haqiqiy PostgreSQL bilan testlar va deployment nusxalari.

**9. P2 — Feed to‘xtatilayotganda polling qayta yaratilishi mumkin.**
